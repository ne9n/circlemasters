## Phase 2: DNS Configuration (30 minutes work + propagation time)

### 2.1 Update DNS Records
**Current State:** circlemasters.com → 199.34.228.59 (Weebly)  
**New State:** circlemasters.com → GitHub Pages IPs

**DNS Changes Required:**

```
DNS Provider: [Your Domain Registrar - Namecheap, GoDaddy, etc.]

CHANGE: A Records (@ or root)
OLD:  199.34.228.59 (Weebly)
NEW:  185.199.108.153
      185.199.109.153
      185.199.110.153
      185.199.111.153

ADD: CNAME Record
Name: www
Value: ne9n.github.io

ADD: TXT Record (for GitHub verification)
Name: _github-challenge-ne9n
Value: [Generated by GitHub - see GitHub Pages settings]
```

**Tasks:**
- [ ] Log into domain registrar
- [ ] Update all A records for root domain (@) to GitHub Pages IPs
- [ ] Add CNAME record for www subdomain
- [ ] Add GitHub verification TXT record
- [ ] Save changes
- [ ] Document timestamp of DNS change

### 2.2 Verify DNS Propagation
**Tasks:**
- [ ] Wait 5-30 minutes for initial propagation
- [ ] Check local DNS: `nslookup circlemasters.com`
- [ ] Check global propagation: https://dnschecker.org/
- [ ] Verify both circlemasters.com and www.circlemasters.com resolve to GitHub Pages
- [ ] Test from different network/ISP if possible
- [ ] Can take up to 48 hours for complete global propagation

## Rollback Plan

If critical issues occur during/after DNS cutover:

1. **Immediate Rollback (anytime within first 3-6 months):**
   - Log into domain registrar
   - Update DNS A records back to: 199.34.228.59 (Weebly)
   - Wait for DNS propagation (5 min - 2 hours)
   - Site automatically reverts to Weebly version
   - No data loss (both versions remain intact)

2. **Post-Rollback Actions:**
   - Document error messages/issues encountered
   - Assess what caused the problem
   - Fix issues in GitHub Pages deployment
   - Redeploy when confident

3. **Re-attempt Cutover:**
   - Update DNS to GitHub Pages again
   - Thoroughly test before making final
   - Keep monitoring for several weeks

## Detailed DNS Instructions

### For Namecheap:
1. Log into Namecheap account
2. Go to Domain List → circlemasters.com → Manage
3. Go to "Advanced DNS" tab
4. Find the A Records section
5. Edit/Delete old Weebly record (199.34.228.59)
6. Add four new A records with values:
   - 185.199.108.153
   - 185.199.109.153
   - 185.199.110.153
   - 185.199.111.153
7. Add CNAME record: www → ne9n.github.io
8. Click Save
9. Wait for propagation

### For GoDaddy:
1. Log into GoDaddy account
2. Go to My Products → Domains → circlemasters.com
3. Click "Manage DNS"
4. Find A records, edit to GitHub Pages IPs
5. Add CNAME record for www
6. Save changes

### For Other Registrars:
- Look for "DNS Management" or "Advanced DNS" section
- Find A records pointing to 199.34.228.59
- Replace with GitHub Pages IPs listed above
- Add CNAME record
- Save changes

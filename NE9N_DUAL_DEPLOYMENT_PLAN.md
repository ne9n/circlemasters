## DNS Instructions by Registrar

### For Namecheap (if that's where you have both)

**For ne9n.com:**
1. Login → Domain List → ne9n.com → Manage
2. Advanced DNS tab
3. A Records: Set to GitHub Pages IPs (185.199.108.153, etc.)
4. Add CNAME: www → ne9n.github.io
5. Save

**For circlemasters.com:**
1. Login → Domain List → circlemasters.com → Manage
2. Advanced DNS tab
3. A Records: Replace Weebly IP with GitHub Pages IPs
4. Add CNAME: www → ne9n.github.io/circlemasters
5. Save

### For GoDaddy

**For each domain:**
1. My Products → Domains
2. Select domain → Manage DNS
3. Update A records
4. Add CNAME for www
5. Save

### For Other Registrars
- Find DNS management section
- Update A records to GitHub Pages IPs
- Add CNAME records
- Save changes

## Important Notes

- **Same GitHub Account:** Both repos under ne9n account makes this easy
- **Independent Sites:** No conflict—each domain uses its own repository
- **Simultaneous Deploy:** Can update DNS for both at the same time
- **Fallback:** Keep Weebly running for circlemasters.com (optional)
- **Free Hosting:** Both get free GitHub Pages with automatic HTTPS
- **Automatic Renewal:** Let's Encrypt SSL certs renew automatically
- **No Backend:** Both sites are static (no server-side code needed)

## Rollback Plan (If Needed)

**For circlemasters.com only:**
- Update DNS A record back to 199.34.228.59 (Weebly)
- Site reverts to Weebly
- No impact on ne9n.com

**For ne9n.com:**
- Update DNS to previous host (wherever it was before)
- Or disable custom domain in GitHub Pages to revert to ne9n.github.io
